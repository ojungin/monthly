# 통합보고서 지표 연결 (Dashboard_DV DB)

회원·활동성·포인트는 플랫폼 통계 사이트의 Supabase 프로젝트 Dashboard_DV에 저장된 `datasets` 집계 데이터를 직접 조회합니다. 비학술 세미나는 기존 Google Sheets raw 직접 조회를 유지합니다.

## 사용 방법

1. 통합보고서 메뉴에서 달력으로 취합 주간을 선택합니다.
2. **통계 DB 계정 연결**에서 플랫폼 통계 개인 계정으로 로그인합니다. 기존 DB의 활성 내부 담당자(super/admin/dv) 권한이 필요합니다.
3. **DB 지표 조회**로 미리보기를 확인합니다. 생성·다운로드 시 DB 집계값과 세미나를 다시 조회해 스냅샷에 반영합니다.
4. DB 연결 해제 또는 보고 사이트 로그아웃 시 통계 연결과 임시 조회값을 비웁니다.

플랫폼 회원 통계 메뉴는 새 창 링크입니다. iframe·공통 비밀번호 자동 입력·비밀번호 기억 기능은 제거했습니다. 통계 DB 인증은 현재 페이지의 메모리에서만 유지하며 비밀번호, 인증 세션을 브라우저 저장소에 저장하지 않습니다. RLS를 변경하거나 익명 접근을 허용하지 않습니다. 시스템 보안 키(`app_secrets`)는 읽지 않습니다.

## 조회 데이터

- 회원: `api|get|dv`, `api|get|pv`, 선택 주간별 `api|get|서비스|{"week":"YYYY-Www"}` 및 DB에 저장된 해당 주 회원 스냅샷
- 닥터빌 활동성: `api|activity`
- 팜빌 활동성: `file|data/pv_activity.enc.json`의 복호화된 DB 데이터
- 닥터빌 포인트: `file|data/points.enc.json`의 DB 데이터
- 팜빌 포인트: `file|data/pv_points.enc.json`의 DB 데이터

파일 이름이 `.enc.json`이어도 여기서는 파일을 다운로드·복호화하지 않고, 해당 키로 DB에 저장된 JSON 집계값만 읽습니다. DB 갱신 시각을 지표 근거에 표시합니다.

원본 업데이트는 플랫폼 통계 사이트에서 수행합니다. 보고 사이트는 DB를 읽기만 하며, 데이터가 없으면 기간·플랫폼을 바꿔 대체하지 않고 자료 미확인으로 안내합니다. 주간 비교는 정확히 7일 전 자료를 사용합니다. 세미나의 날짜·완료 여부·제목·신청·시청·만족도·유용도 조회 방식은 동일합니다.

## 공용 문서 저장

지표 포함 공용 저장에는 기존 `supabase/weekly-summary.sql`의 문서 생성 함수가 필요합니다. 이 설정은 보고 사이트의 저장소이며 Dashboard_DV의 데이터 조회 권한과 별개입니다. 조회값은 문서 스냅샷에 보관되므로 보관 문서를 열 때는 재조회하지 않습니다.

## 검증

DB 키·기간·플랫폼 분리, 전주 비교, 누락 자료, 세미나 실패의 독립 처리, 자동 로그인 제거와 비영구 세션 설정을 테스트합니다. 실제 데이터 조회는 권한 있는 통계 개인 계정으로 로그인한 뒤 확인해야 합니다.
