# 個人 목표 설정 / KPI 권한
개인 목표는 첨부한 1세트 양식에 맞춰 이름을 묶은 5개 행으로 저장합니다. 실행 계획을 선택하면 사업부 목표·팀 단위 실행 목표와 반기/분기 전략을 자동 표시합니다. 개인목표, 방법, 평가지표(산출물), 목표일정, 100·90·80·70·60점의 평가 기준 및 비고를 작성합니다. 세트 추가는 5개 행을 한 번에 추가합니다.

## DB 적용
보고 사이트 Supabase 프로젝트 `qoabsfqxufdzcjhgrceq`의 SQL Editor에서 `supabase/personal-goals.sql`을 실행합니다. 기존 `team_goals`, `team_goal_strategies` 표와 등록한 내용을 보존하면서 입력·수정 정책을 관리자/책임자 전용으로 제한하고 `personal_goal_sets` 표를 추가합니다.
- 현 계정 모델에서 `members.role='admin'`은 관리자/책임자입니다.
- 팀 목표·전략: 등록된 팀원 전체 조회, 관리자/책임자만 입력·수정.
- 개인 목표: 관리자/책임자는 전체 조회·입력·수정, 팀원은 본인 세트 조회만 가능.
- 익명 접근은 불가. 삭제 권한은 추가하지 않습니다.
- 목표 세트는 5개 행, 한 행 이상 완성 필요. 선택 계획과 세트 연도 일치 및 필수 입력을 DB에서 검증합니다.
- DB 설정 전에는 개인 목표를 저장하지 않으며, 브라우저 저장소에 개인 KPI를 보관하지 않습니다.

## 출력
각 세트마다 Excel(.xlsx) 및 PDF를 별도로 출력합니다. Excel은 세트당 한 시트, 이름 칸과 5개 점수 헤더를 원본처럼 병합합니다. PDF는 열을 모두 보존하도록 A3 가로 양식으로 생성합니다. 등록된 팀원 이름과 상위 목표, 선택한 실행 전략, 개인 입력값, 비고가 함께 출력됩니다.
