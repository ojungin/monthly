# 주간보고서 디자인 기준

사용자 첨부 banner_archive.html의 닥터빌 웹 디자인 및 범용 블루 배너 규칙을 기준으로 보고서 형식을 구성했습니다.

- 제목 30px/600, 섹션 제목 22px/600, 본문 15px, 메타 12px.
- 기본 서체 Pretendard, 설치되지 않은 환경은 Apple SD Gothic Neo 또는 맑은 고딕으로 대체합니다.
- 닥터빌 primary #626EE6, 링크·서브 내비게이션 #2F80FF, 본문 #333333, 제목 #1E1E1E, 보조 #666666.
- 카드 테두리 #E1E1E1, 표·모듈 배경 #EAEEF2, 둥근 모서리 10px.
- 범용 블루 배너 #46A3F2 → #6A4FE6를 보고서 표지 영역에 적용했습니다.
- 0~6번 구성을 유지하고 금요일 제출 마감일, 제출·업무·완료 현황을 상단에 표시합니다.
- 화면·HTML·PDF는 동일한 reportStyles와 weeklyBody를 사용합니다. Word는 동일 내용에 제목·표 색상과 서체를 적용하며 Excel은 한 시트의 제목·헤더·테두리 색상으로 같은 규칙을 반영합니다.
- 업로드된 아카이브의 원본 화면 캡처와 배너 샘플 데이터는 저장소에 복사하지 않았습니다.
